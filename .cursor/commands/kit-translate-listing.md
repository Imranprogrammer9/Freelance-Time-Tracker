You are running **`/kit-translate-listing`** for NowKit.

Goal: translate the **store listing metadata** — app name, short description,
long description, and the current "What's new" changelog — from English into one
or more developer-picked languages, written in Play's per-locale folder layout so
they're easy to paste into Play Console (or push with Fastlane later).

This is the listing-copy sibling of **`/kit-translate`** (which translates the
*in-app* strings). Run it after the English listing exists.

Audience: first-time mobile developers / vibe coders. You do the work; they pick
the languages.

**Docs:** https://kit.shipkaro.dev/docs/release

## Step 1 — Pre-flight: the English source files

These are the source of truth (generated by `/kit-generate-aso` +
`/kit-generate-changelog`):

- `playstore/title.txt` — app name (**≤ 30 chars**)
- `playstore/short_description.txt` — short description (**≤ 80 chars**)
- `playstore/full_description.txt` — long description (**≤ 4000 chars**)
- `playstore/changelogs/<versionCode>.txt` — current "What's new" (**≤ 500 chars**)

Check which exist. If `title` / `short` / `full` are missing, tell the developer
to run `/kit-generate-aso` first. If the changelog is missing, offer to run
`/kit-generate-changelog` first (or skip translating the changelog). Read the
current `versionCode` from `app/build.gradle.kts` to know the changelog filename.

## Step 2 — Pick language buckets

Ask with the **AskUserQuestion** tool, **multi-select**, with these options
(same language set as `/kit-translate` so the app and its listing stay in sync):

- **Label:** `Match my app's languages`
  **Description:** Translate the listing into the same locales the app already
  ships (read from `res/values-*/` folders). Recommended — keeps store + app
  consistent.
- **Label:** `Right-to-Left (RTL)`
  **Description:** Arabic (ar), Hebrew (iw), Urdu (ur).
- **Label:** `Asia`
  **Description:** Simplified Chinese (zh-CN), Traditional Chinese (zh-TW),
  Japanese (ja-JP), Korean (ko-KR), Hindi (hi-IN), Thai (th), Vietnamese (vi),
  Indonesian (id), Malay (ms), Filipino (fil).
- **Label:** `Europe`
  **Description:** German (de-DE), Spanish (es-ES), French (fr-FR), Italian
  (it-IT), Portuguese (pt-PT / pt-BR), Dutch (nl-NL), Russian (ru-RU), Polish
  (pl-PL), Turkish (tr-TR), and more on request.

Use **Play Console locale codes** (e.g. `de-DE`, `es-ES`, `ja-JP`, `zh-CN`) for
the folder names — these differ slightly from the Android `res/values-*` codes
(e.g. Play uses `iw` for Hebrew, `de-DE` not `de`). If the developer picks "Match
my app's languages", map each `res/values-xx` to its Play locale code.

The auto-added **Other** option lets them name specific languages. If only a
"keep English" intent is expressed (or nothing), do nothing and stop.

## Step 3 — Translate, respecting Play's char limits

For each target locale, translate each file. **Hard rules:**

- **Title ≤ 30, short ≤ 80, changelog ≤ 500, long ≤ 4000 characters** — counts
  apply *per language*. Translations are often longer than English; if a
  translation overflows, **shorten it naturally** (don't just truncate
  mid-word) until it fits.
- Keep the **tone + keywords** of the ASO copy — this is marketing text, not a
  literal translation. Localise idioms; keep the value proposition.
- Leave brand names, the app name's distinctive part, and product names
  untranslated unless the developer says otherwise.
- Don't translate the changelog if the developer opted to skip it.

## Step 4 — Write Play's per-locale layout

For each locale write:

    playstore/listings/<play-locale>/title.txt
    playstore/listings/<play-locale>/short_description.txt
    playstore/listings/<play-locale>/full_description.txt
    playstore/listings/<play-locale>/changelogs/<versionCode>.txt

Create directories as needed. (This mirrors the Fastlane `supply` metadata
layout, so the developer can automate uploads later.) Print a short table of
locale → char counts so the developer can spot anything near a limit.

## Step 5 — How to use them

Show this verbatim:

> **Add your translated listing in Play Console:**
> 1. **Grow users → Store presence → Main store listing** → language dropdown
>    (top) → **Manage translations → Add your own translations** → pick each
>    language you translated.
> 2. For each, paste **title**, **short description**, **full description** from
>    `playstore/listings/<locale>/`.
> 3. **What's new:** on your release, the **release notes** field has a per-language
>    tab — paste each `playstore/listings/<locale>/changelogs/<versionCode>.txt`.
>
> (Later you can automate all of this with Fastlane `supply` — the folder layout
> above already matches what it expects.)

## Wrap up

Summarise: which locales were translated, where the files are, and any value that
came close to a char limit and was shortened. Mention `/kit-translate` for the
in-app strings if they haven't run it.
