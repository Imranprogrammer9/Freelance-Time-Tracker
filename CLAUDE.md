# NowKit

Project context for Claude Code. The full agent guide lives in `AGENTS.md` (shared by all AI
agents — Claude Code, Cursor, Antigravity, OpenCode) and is imported below.

**At session start, if a `.session/` directory exists, read `.session/PROGRESS.md` first** (plus the
latest `.session/*-summary.md`) before doing any work — it holds the kit author's running log,
decisions, and known issues that aren't derivable from the code. Skip silently if `.session/` is
absent (it's git-ignored and ships only on the author's machine).
